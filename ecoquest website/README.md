# EcoQuest 🌿

A responsive, browser-based environmental education and gamification web app inspired by Sri Lanka.

## Features
- Six daily real-world environmental challenges with points
- Five-question interactive environmental quiz
- Growing virtual garden and levels
- Unlockable achievement badges
- Light/dark themes and editable explorer name
- Browser-based progress persistence using localStorage
- Responsive desktop and mobile layouts

## Run locally
Open `index.html` in any modern browser. No installation or API key needed.

## Deploy
Push the files to a public GitHub repository, then import the repository into Vercel (Framework Preset: Other; no build command) or enable GitHub Pages in Settings > Pages.

## Data and limitations
All data is stored in the user's own browser; there are no accounts or cloud synchronization. Challenge completion is self-reported, and the garden is a symbolic game mechanic, not an environmental impact estimate. Quiz rewards are limited to one claim per local calendar day.

## Technology
Vanilla HTML, CSS, JavaScript. No external dependencies.

## Originality
An original educational demo created for a website competition. Customize and extend it with your own research, artwork, and features before submission.
