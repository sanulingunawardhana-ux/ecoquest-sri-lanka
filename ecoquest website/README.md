# 🌿 EcoQuest Sri Lanka

**Learn. Act. Grow.** A responsive environmental learning web application that turns small daily actions into an interactive game.

**Live demo:** https://ecoquest-sri-lanka.vercel.app/

## The problem
Environmental awareness is important, but learning about sustainable habits can feel abstract. EcoQuest helps learners explore practical habits through short challenges, quizzes, visual rewards, and personal progress tracking.

## Features
- Daily environmental challenges, a featured quest, eco-points and activity streaks
- Timed quizzes with Easy, Medium and Hard difficulty levels
- Virtual garden with growing plants and wildlife unlocks
- Achievement badges and a downloadable in-app certificate
- Personal analytics, activity history and quiz results
- Light and dark themes, editable explorer name, responsive layout
- Privacy-friendly local progress storage: no account or database required

## Technology
HTML5, CSS3, vanilla JavaScript and browser `localStorage`. No framework, API key or paid backend is needed.

## Run locally
Open `index.html` in a modern browser.

## Deploy
Upload `index.html` to GitHub and import the repository into Vercel. Select **Other** as the framework preset and set the root directory to the folder containing `index.html`.

## How to use
1. Open **Challenges** and complete an action in real life before marking it done.
2. Visit **Eco Quiz** to practise environmental knowledge.
3. Explore **My Garden**, **Achievements**, and **My Progress** to see your personal milestones.
4. Use **Settings** to change your display name, theme, or reset local progress.

## Privacy and limitations
Progress is saved only in the current browser/device. There is no cross-device sync or shared leaderboard. Challenge completion is self-reported. Eco-points, garden growth, and achievements are game rewards, not independently verified environmental impact. Certificates are in-app achievements, not accredited awards.
